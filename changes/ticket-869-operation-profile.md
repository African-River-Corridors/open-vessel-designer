- The operation profile of a Type C tank's holding time (issue #869, spec 0016): eight new inputs in the group "Gas tanks" for Type C tank Options. `holding_profile` is a list of legs, each a state (`laden_passage` or `idle`), a length in days, for a passage leg a typed passage speed and for an idle leg a typed gas use; the default is the design basis of 20 days laden passage then 10 days idle, marked default. The others are a named preset (`none`, `bv_nr467`, `bv_nr217`; never applied by default), the minimum guaranteed gas use for the ADN row and the domestic load for the IGF row (both zero), the journey duration for ADN, the start pressure of the cargo tanks, the normal service pressure of a fuel tank and a typed fill (all none). A profile with an unknown state, a length of zero or less, or a negative speed or use is refused with a message. A passage leg with no typed speed takes the Option's design service speed, marked default; a typed speed overrides it. The passage credit is zero when the Option has no gas-fuelled consumer. A file saved before reads the defaults, marked default, with one note per Option, and keeps its results hash. Inputs only: no result reads them yet.
