- Damage is a second stage in the Python API, with progress and cancel, issue #940. `ovd.simulate.simulate_damage(params, progress=None, cancel=None)` builds the Option as `simulate` does and runs the damage cases. Its result equals `simulate(params, damage=True)` on the whole value. `progress(done, total)` is called as cases finish; `cancel()` returning true stops the run and the call returns the results with `damage_status` `not run`. Both are called on the calling thread, so Ctrl-C raises `KeyboardInterrupt` and an exception in either is raised from the call. The compiled core now lets go of the GIL while it calculates, in `eval` as well, so other Python threads run during a call. No result moves.
