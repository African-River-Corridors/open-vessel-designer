- The holding-time model of a Type C LNG tank (issue #870, spec 0016): the tank is stepped hourly through the operation profile as a closed homogeneous tank of methane (one saturation state, no thermal stratification, so the real pressure can rise faster), from the loading limit at the start pressure. The loading limit is LL = FL x rhoR / rhoL at the relief setting (IGC Code 15.1.3.1, always); a typed fill above it is refused. The heat leak is recomputed each step from the cargo temperature at the air ambient of the rule over the whole tank surface (IGC Code 7.2: 45 C; ADN 9.3.1.24.2: 30 C). A gas use above the vapour available is capped and reported; the pressure never falls below the start pressure. The result gains a `holding_time` block (the design-basis row, per-leg pressure and fill, the hourly series, the gas-use credit, each input with its source), kept out of the results hash. The model is not in the solve yet: no design pressure, wall, weight or other result moves.
