- Service Area (issue #925): the Service Area is a required input with no default, read the same way by `ovd run`, `validate`, `fill`, the app and `simulate` (so the Python API), for every vessel type. A Design with none is an error with one message that names `river-only` and `coastal-and-river` and the fix. `ovd fill --service-area <value>` and `ovd new --service-area <value>` set it, as typed. Before, a missing one read as river-only in `run` and the app, and applied no Rule Sets in `simulate`. The app shows the field with nothing chosen. A file saved before the input existed is an error until it is set. `website/assets/examples/lrg-gas-89.vdesign` now states river-only (written with `ovd fill --service-area river-only`, which also writes the inputs a version 2 file lacks, as any `fill` does; its triangle budgets did not move). No design in the design-impact set moves.
