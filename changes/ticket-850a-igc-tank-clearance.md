- New Rule Set `igc-tank-clearance` 1.0.0 (issue #850, part A of two): the two IGC 2.4.1.2 rows, `igc/2.4.1.2/side-clearance` and `igc/2.4.1.2/bottom-clearance`, with the d(Vc) table, exactly as `igc-2g` holds them (the same rule ids and content, so a stack can hold both sets). It exists so that a Rule Set stack that takes ADN 9.3.1 (`adn-gas`) as its design Rule Set, in place of `igc-2g`, can keep the two rows that size the tank clearance, because the double-hull branch of ADN 9.3.1.11.2 (a) gives no distance from the tank to the hull. On a stack that holds `adn-gas` and `igc-tank-clearance` and not `igc-2g`, the Rule Trace rows of those two Rules carry a `note` that says they size the tank. No default stack holds the set yet (part B, the river-only gas stack, follows), so no design result changes. Text read: IGC Code, resolution MSC.370(93), 2.4.1.1, 2.4.1.2 and 2.4.2 (annex pp. 20-21); the six amendments read change neither 2.3 nor 2.4. The two rows keep their verified status (they are the same Rules as in `igc-2g`).
