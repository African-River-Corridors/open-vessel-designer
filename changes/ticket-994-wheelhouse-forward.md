- New Arrangement Style `wheelhouse_forward`, issue #994, flagged for a hazard study. The machinery and the main accommodation stay aft in a deckhouse; the wheelhouse stands in a small house over the forepeak, with a watch room and a muster point. If the bow rake is too short for the house, the house takes cargo length and a warning says how much. The house is steel by volume, joins the gross tonnage and is priced on its floor. No existing style moves: no design in the design-impact set changes and every fixture hash matches. The house sizes are estimates. First of several changes for this style.
