- Opening inputs and a Measure for the IGC 3.2.4 Rules (issue #913, part 1): a Rule's Applicability may now name five object inputs of the `opening` object, `opening_kind`, `opening_space`, `opening_face`, `opening_openable` and `opening_gas_tight` (the last two take `yes` or `no`), so a Rule picks the openings it governs, as `loading_condition_kind` does for loading conditions. New Measure `opening.clear_of_cargo_face` (true when the opening is not on the deckhouse end that faces the cargo area: the negation of `opening.faces_cargo_area`, so a `check` Rule passes on it). No Rule Set changes in this step and no verdict moves.
