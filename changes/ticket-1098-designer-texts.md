- Texts for designers (issue #1098). The help an input shows under "About this input" (its basis in the Defaults Profile) no longer cites issue numbers, spec numbers, repository files or code paths, and names another input by its label, not its key. 167 texts changed; no value, default or results hash moves. The minimum freeboard help is now four short sentences: what the safety clearance is, its default (ES-TRIN 2025/1 Article 4.01(1)), that it is not an ICLL freeboard, and its limit. The crude oil and diesel Cargo descriptions say their density in plain words, and the wizard no longer hides a description that holds `::`. A choice, a switch or a list input now carries its basis in the input schema too, and the four required choices (Cargo, Formation, Hull Form, Service Area) each have one, so each has "About this input". The example no longer states a tank count the search may change. A new test (`designer_texts.rs`) fails when a text for designers holds `::`, an issue number, a Rule Set id with a version, a spec number or a repository file.
